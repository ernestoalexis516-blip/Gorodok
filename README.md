# Городок

Браузерная градостроительная игра про Россию (Three.js, без сборки). 47 построек в 10 разделах, система нужд (свет, вода, тепло, еда, медицина, школы, порядок, досуг, мусор), работа, вокзалы и поезда. Ландшафтный режим, главное меню, автосохранение.

## Запуск
Откройте `index.html` в браузере (нужен интернет для загрузки Three.js с CDN).

## GitHub Pages
Загрузите все файлы в корень репозитория, затем Settings -> Pages -> Deploy from a branch -> main / root.

## Файлы
- `index.html` - страница и меню
- `style.css` - оформление
- `buildings.js` - список построек, разделов и нужд (сюда добавляют новые здания)
- `game.js` - логика игры и 3D-модели
